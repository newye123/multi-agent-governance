# 案例一：后台 Agent 被「用户插一句话」杀死

> 来源：真实项目的夜间值班记录（2026-09-22 第 21 轮复验与拍板）。
> 这份案例讲的不是「Agent 挂了」，是**挂了之后没人知道**。

## 现象

凌晨 01:05 做复验，发现一棵候选树上有两个文件被改过，但从未提交。

- `mtime` 停在 **22:15:18 / 22:16:24**
- 该树最后一次 commit 是 **19:40**
- 复核时刻距最后一次改动 **近 2 小时 50 分**，期间该树零落盘

当时的第一判断是：「B 正在这棵树上飞行中提交，先别动。」

**这个判断是错的。**

## 一开始以为

复验记录里原话是：

> 我把「B 正在由候选树持有人飞行中提交」写错了。

错在哪？错在把「文件被改过」当成了「有人在改」。

判据很简单：**mtime 停在两个小时前，就不是「正在写」，是「写了一半人没了」。**

## 取证

三行命令，三个读数：

```bash
$ git -C <树> status --porcelain
 M src/.../two-files        # 两个文件已改未提交

$ git -C <树> log --format=%H%x20%ad -1
<sha> 2026-09-21 19:40     # 最后一次提交在两小时前

$ find <树>/src -newermt '-10 minutes' -type f | head
（空）                      # 十分钟内没有任何写入
```

三条读数合起来只有一个解释：**这棵树上有孤儿改动，没有人会回来提交它。**

## 人是怎么没的

同项目的记忆库里另有一条记录（由另一个控制器实例写下），原文：

> 一手 `Agent(run_in_background)` 被打断连带杀死，盘上只剩两个已改未提交的文件，之后 3h40m 该树零落盘。

关键短语是**「被打断连带杀死」**。触发条件不是崩溃、不是超时、不是 token 耗尽——是**用户在对话里插了一句话**。

后台 Agent 的上下文挂在主对话上。主对话被用户的新输入打断，后台 Agent 连带终止，**且不发完成通知**。

于是：任务没有完成、没有报错、没有通知、没有回包。**它只是安静地消失了，留下一个半成品现场。**

## 代价

那 5 行改动是「死在半路的孤儿」。记录里的判断很直接：

> 明早的窗口会因此红在打包那一步。

也就是说：一个本该在两小时前完成的活，不但没完成，还会让第二天的发布窗口失败。而失败原因看起来会像是「打包脚本有问题」——离真正的原因隔了三层。

## 结论

| 项 | 判定 |
|---|---|
| 任务是否完成 | 否 |
| 是否有错误信号 | **没有**（这是最致命的） |
| 现场是否可恢复 | 是（两个文件还在盘上，未提交） |
| 根因 | 后台 Agent 生命周期挂在主对话上，用户插话即连带终止 |
| 制度缺陷 | 派了后台 Agent 干长活；且没有超时检测机制 |

## 修复：两条规则

**规则一：长活只派 chat 会话，不派后台 Agent。**

判据按预计时长与副作用分：

```
预计 < 3 分钟、纯只读探针、可丢 → 后台 Agent（可被打断，无所谓）
预计 > 3 分钟 / 会写文件 / 跨夜 / 需要回包 → chat 会话
```

**规则二：必须能发现「人没了」。**

有了规则一还不够——chat 会话也会挂。所以要有**挂死检测**：

> 超过约定时限无回包文件 → 判挂死，槽位回收，改派续做（现场以最近一次补丁/提交为准）。

注意这条判据是「**无回包文件**」，不是「无响应」。因为会话不回话是常态，回包文件缺失才是可观测信号。

## 可迁移的判据

> **派 Agent 干重活 = 主动制造孤儿现场。**

三条自查：

1. **这个任务会不会写文件？** 会 → 不能派给可被打断的执行体。
2. **失败时我能收到信号吗？** 不能 → 这个任务不能派出去，或者必须配一个超时检测。
3. **现场丢了，损失是什么？** 是「重跑一次」还是「几小时的工作 + 一棵脏树」？后者不可接受。

第 2 条最容易被忽略。大多数编排讨论关心「任务能不能完成」，很少关心「完不成的时候，你怎么知道」。

## 制度上的对应

- **派工决策树 树 2**：按预计时长与副作用选执行体，不按习惯选。
- **编制册「挂死检测」**：超时无回包 → 判挂起 → 巡检手核对现场（porcelain / mtime）→ 先保存孤儿现场再续派。
- **复验单第 5 项**：产物已提交，或回包显式声明未提交并给出可恢复路径。**这一项就是为了让「人没了」不至于变成「活白干」**。
